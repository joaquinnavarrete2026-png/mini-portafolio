# Mini-Portafolio Web - Evaluación

Mini-portafolio personal desarrollado con **React**, **Vite**, **React Router** y **Tailwind CSS**.

## 🚀 Tecnologías utilizadas
* React 19 / Vite
* React Router DOM (para las 5 rutas: Inicio, Sobre mí, Habilidades, Proyectos, Contacto)
* Tailwind CSS (para el diseño y componentes responsivos)

1. Clona este repositorio o descomprime la carpeta del proyecto.
